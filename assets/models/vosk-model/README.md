# Vosk Offline Speech Recognition Model Directory

Place your offline Vosk model files (or unzipped model folder) here.
For example, download from https://alphacephei.com/vosk/models:
- `vosk-model-small-en-us-0.15` (English lightweight ~40MB)
- `vosk-model-small-bn-0.4` (Bengali lightweight)

The model directory typically contains:
- `am/`
- `conf/`
- `graph/`
- `ivector/`
